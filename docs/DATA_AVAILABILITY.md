# Data availability

Status checked on 26 October 2026.

The public repository includes the individual results of all 126720 searches,
input datasets, frozen protocols, power plans, statistical tables and three
examples of complete primary observations. It supports recomputation of the
reported statistics and reconstruction of these examples. It does not include
complete primary observations for all 351216000 objective evaluations.

The author's preserved full archive is **not publicly hosted**. There is no
public download URL or DOI (Digital Object Identifier) for it as of this date:

a download link or a promise of public access. Access can be discussed with
the author through [repository issues](https://github.com/Inkizhekov/pso-ocba-noise-budget/issues).
No external independent replication is claimed. A complete replay of all
primary observations requires that separate archive or new scientific runs.
