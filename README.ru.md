Статья и приложения содержат краткие описания наборов данных и ссылки на первоисточники UCI. Численные результаты сохранены.

## Подготовка данных

После загрузки всего репозитория восстановите сжатую таблицу результатов и проверьте комплект:

```powershell
py -3.13 prepare_data.py
py -3.13 verify_reviewer_package.py
```

Скрипт не обращается к сети и сверяет исходные байты по SHA-256. [Порядок публикации через браузер](docs/GITHUB_UPLOAD_RU.md).

## Объем данных и границы проверки

Таблицы охватывают все семь научных серий статьи: 3806 заданий,
126720 поисков, 351216000 поисковых оценок и 28080 итоговых обучений.
Серия исходных малых бюджетов сохранена как научный материал приложения,
а не как история разработки.

Все первичные наблюдения включены только для трех контрольных заданий.
Полные трассы всех поисков сохранены в отдельном архиве
`ocba_reviewer_full_20261024.zip`, который пока не опубликован в интернете.
[Размер, SHA-256 и точный статус доступности](docs/DATA_AVAILABILITY.md).
Этот минимальный комплект позволяет
пересчитать статистику по результатам поисков и проверить контрольные
трассы, но не заменяет полный архив для аудита каждого наблюдения.

`data/job_inventory.csv` содержит учет всех официальных заданий.
`data/source_equivalence.json` сохраняет отчет первоначального публичного
выпуска. После исправления метаданных шума он не является утверждением
о тождественности текущих исходников. См. [описание исправлений](docs/RELEASE_NOTES.md).

Каталог `historical` содержит только три файла, необходимые существующим
импортам Python, включая реализацию нейросетевой функции качества.
Полной истории разработок в нем нет.

## Проверка без научных зависимостей

Из корня распакованного комплекта:

```powershell
py -3.13 verify_reviewer_package.py
```

Проверяются контрольные суммы научных материалов, комплектность
результатов поисков, бюджеты и учет итоговых нейросетевых обучений.
Правки кода и документации не блокируют эти проверки. Для проверки всех
байтов выпуска используйте `prepare_data.py --verify-only --strict-release`
и `verify_reviewer_package.py --strict-release`.

## Установка и пересчет

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe verify_reviewer_package.py --recompute
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Пересчет восстанавливает сравнения исходной серии, 1944 расширенных
ранговых сравнения, нейросетевые сравнения, семьи 23 и 72, пять контрастов
новых экземпляров, исключение семейств, иерархическую чувствительность,
условный минимально обнаружимый эффект, диагностику траекторий и
контрольные примеры первичных журналов. Полные поиски и все нейросетевые
обучения заново не выполняются. Результаты проверки сохраняются
в новом каталоге `reviewer_checks`.

Скачайте весь репозиторий через Code / Download ZIP, распакуйте и запустите prepare_data.py перед проверкой.

Manifest `reviewer_package_manifest.json` содержит контрольные суммы
восстановленных файлов, а `github_payload_manifest.json` - загруженного
представления. Сами manifest зафиксированы Git-коммитом и не включают
друг друга во избежание циклических сумм. Отдельного `.zip.sha256` для
GitHub ZIP здесь нет. [Проверка и обновление manifest](docs/GITHUB_UPLOAD_RU.md).

## Новые запуски

```powershell
.\.venv\Scripts\python.exe experiment.py --dry-run --out results/new_study
.\.venv\Scripts\python.exe experiment.py --smoke --workers 1 --out results/new_study_smoke
```

Полный расчет подробно описан в руководстве и английском README.
Используйте новый каталог результатов: исходные научные протоколы
и данные статьи не переписываются. Равное число оценок не означает
равное реальное время. Внешнее независимое воспроизведение не заявляется.
